Attention Lab · Design research → working code

Twenty ways to
earn a second look

Interactive concepts exploring how motion catches — and keeps — attention: kinetic type, scroll-driven narrative, tactile micro-interactions, cursor-led reveals, and the choreography of notification. Every demo is a single self-contained HTML file with zero dependencies, and every one honors prefers-reduced-motion. Open the “About” panel inside any demo for the mechanism and the exact timing values.

Built from the research in research/attention-motion-design-research.md. The shared rules: entrances decelerate, exits accelerate and run faster; micro-feedback lands in 100–200ms; staggers run 30–80ms apart; only transform, opacity and filter animate on the hot path; ambient loops stay slow and yield entirely under reduced motion.
