06Cursor & Spotlight

Cursor as character + spotlight reveal

The cursor becomes a designed object: a dot with a spring-lagged ring that morphs by context (grows on links, becomes a “VIEW” pill over work items) — and a section where it turns into a literal spotlight, unmasking a hidden vivid layer.

Why it catches attention: the cursor is the one pixel users already watch. Giving it mass and personality creates constant, self-directed motion; the spotlight adds a curiosity gap — you can see there is more page than you're being shown, so you sweep to uncover it.

Craft notes: dot tracks 1:1; ring follows with lerp 0.16/frame for a ~90ms lag that implies weight; state morphs run 300ms on cubic-bezier(.16,1,.3,1). Spotlight is a CSS mask-image radial circle whose radius springs 0→220px on entry and position lerps at 0.2/frame.

Reduced motion (and touch devices): the native cursor is kept, the ring is not rendered, and the lit layer displays fully unmasked — no content is gated behind pointer motion.
